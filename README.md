Number Guessing Game (C++)

About the Project

The Number Guessing Game is a simple console-based game developed using C++. The computer generates a random number between 1 and 100, and the player has to guess the correct number.

The game provides hints such as “Too High” or “Too Low” after each guess. It also counts the total number of attempts taken by the player.

Features

* Generates a random number between 1 and 100.
* Allows the player to enter guesses.
* Provides hints for incorrect guesses.
* Counts the total number of attempts.
* Displays a congratulatory message when the correct number is guessed.

OOPS Concepts Used

* Class: NumberGuessingGame
* Object: game
* Encapsulation: Uses private data members.
* Constructor: Initializes the secret number and attempts.
* Member Function: play() controls the game.

Technologies Used

* Programming Language: C++
* Libraries: iostream, cstdlib, ctime

How to Run

1. Download or clone the repository.
2. Open the C++ source file in a C++ compiler.
3. Compile and run the program.
4. Enter your guesses.
5. Follow the hints until you guess the correct number.
